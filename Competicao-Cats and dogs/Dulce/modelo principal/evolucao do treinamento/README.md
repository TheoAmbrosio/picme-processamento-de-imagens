# Evolução do treinamento — Dulce

Perda e acurácia de treino/validação por época, conforme fontes salvas.
As duas séries de100 épocas são do primeiro modelo cats_and_dogs.ipynb, SGD LR0.01, conforme esclarecimento da autora. acc_val_modelo_fechado é a execução original (só validação); repeticao é outra execução com mesma configuração e seed, feita depois para registrar as quatro métricas. Não são continuação nem reconstrução exata das métricas de treino da execução original. JSON preserva mais precisão que logs impressos; execuções não foram concatenadas.
